🎮 Valorant Comp Roller

A lightweight web application that generates randomized competitive Valorant team compositions.

Instead of defaulting to the same meta agents every game, this app helps players experiment with new team strategies and combinations.

🔗 Live Demo: (https://oomaximus-valorant-comp-roller-2e4b.vercel.app/)

🧠 How It Works

The application:

Stores a predefined list of Valorant agents.

Randomly selects agents while preventing duplicates.

Dynamically renders the generated team composition to the UI.

Allows users to re-roll compositions instantly.

The focus was clean logic flow and separation of concerns between UI rendering and generation logic.
